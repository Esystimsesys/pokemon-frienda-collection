# フレンダピックずかん

ポケモンフレンダのピック958枚を記録できるようにした図鑑。

**https://esystimsesys.github.io/pokemon-frienda-collection/**

iPad や iPhone の Safari で開いて「ホーム画面に追加」すると、全画面のアプリとして起動する。
画像は一度読み込めば、オフラインでも見られる。

主に使うのは iPad だが、スマートフォンの幅（320〜430px）でも一通り使えるようにしてある。
幅 600px を境に並べ方を変えていて、判定は `src/lib/responsive.ts` にまとめてある。

| | iPad（600px以上） | スマートフォン（600px未満） |
|---|---|---|
| ずかん上のボタン | 5つを1行 | あつめた数＋とうろく／ほかの画面へ の2行 |
| カードの大きさ | 目安どおり（140〜260px） | 目安を0.62倍して 4〜2列から選べる |
| 小さいカードの ＋ | 出す | 出さない（絵をタップして数える。− だけ置く） |
| しぼりこみの「だん」 | 13こを折り返して全部見せる | よこスクロール（折り返すと画面が埋まるため） |
| ピックのじょうほう | ‹ › を券面の左右に置く | ‹ › を券面に重ねて、絵を画面いっぱいに |
| おおきく見る | 下に「うらを みる」 | よこ向きのときはボタンを右下に重ねる |

## 作りの前提

- **PWA**（ホーム画面webアプリ）。App Store には出さない
- **画面に漢字を使わない**（5歳児が使うため）。ただし後述の管理ツールは大人が使うので漢字を使う
- 所持データは**その端末の localStorage にだけ**入る。サーバーには送らない
- 写真からの自動認識は**しない**（券面の2Dコードは QR ではなく独自形式。スペシャル120枚には裏面にIDが印字されていない）
- マスタは**公式サイト pokemonfrienda.com** を第一とする

| `npm start` / `npm run web` | 開発サーバー |
| `npm run update` | 公式を見に行ってデータを作り直す |
| `npm run gaps` | データの欠けを一覧（`-- -v` でIDも） |

（弾の一覧は公式サイトのナビから自動で見つける）。

## 公開の仕組み（GitHub Pages）

`main` に push すると `.github/workflows/deploy.yml` が走る。

    npm ci → npx tsc --noEmit → npm run build:web → dist/ をアーティファクトに → Pages が配信

**ビルド成果物はどのブランチにもコミットされない**（アーティファクトとして渡すだけ）。
リポジトリにはソースだけが入る。

リポジトリ名がURLに入るので、ビルド時に `EXPO_BASE_URL=/リポジトリ名` を渡している
（ワークフローがリポジトリ名から自動で決める。`ユーザー名.github.io` という名前なら空になる）。
これに合わせて `public/index.html`・`public/manifest.json`・生成される `sw.js` は
**すべて相対パス**にしてあるので、ルート配信でもサブパス配信でもそのまま動く。

GitHub Pages には書き換えの設定が無いため、`dist/404.html` に `index.html` と同じものを置いて
直リンクに対応している（HTTPステータスは404のままだが、画面は出て JS が正しく遷移する）。

### 知っておくこと

- **`sw.js` のキャッシュは10分固定**（GitHub Pages はヘッダーを指定できない）。
  直したものが端末に届くまで最大10分かかる。
- **直リンクは HTTP 404 が返る**（`404.html` のおかげで画面は出て、JS も正しく遷移する）。
  Service Worker が入った後はそちらが処理するので、影響は初回だけ。

⚠️ 公開URLなので誰でも見られる。所持データは端末内にしか無いので外には出ない。

## コミットとブランチ

コミットメッセージは [Conventional Commits](https://www.conventionalcommits.org/ja/v1.0.0/)
に沿って書く。**大きめの改修は作業用ブランチを作る**。`main` への push が
そのまま公開になるので、作りかけを子供の画面に出さないため。

このリポジトリだけの決めごと:

| | |
|---|---|
| 型に `data` を足す | `src/data/*.json` や `assets/types/*.png` の作り直し |
| よく使う範囲 | `list` `detail` `party` `trainers` `record` / `search` `filter` `collection` / `sw` `pwa` / `ocr` `icons` `scripts` |
| `BREAKING CHANGE` | 所持データ（localStorage）の形が変わって、今まで登録したぶんが読めなくなるとき。子供の記録が消えるので必ず明示する |
| main に入れる前 | `npx tsc --noEmit` と `npm run build:web` を通す。落ちたまま push すると公開が止まる |

`git commit` で出る雛形は `.gitmessage`。クローンし直したら、設定を1回だけ実行する。

```sh
git config commit.template .gitmessage
```

## お断り

個人が趣味で作ったもので、株式会社ポケモン・タカラトミーアーツ・ゲームフリークとは
一切関係がない。「ポケットモンスター」「ポケモンフレンダ」およびピックの絵柄・
ポケモンの名称などの権利は、それぞれの権利者に帰属する。

- ピックの画像はリポジトリに同梱しておらず、公式サイト（pokemonfrienda.com）から
  読み込んでいる。
- `src/data/*.json` は、公式サイトの掲載内容と公式の券面画像から機械的に取り出した
  ものを含む。
- `assets/types/*.png`（18タイプのマーク）は公式の券面画像から切り出したもの
  （`npm run build:type-icons` で作り直せる）。

権利者からの申し出があれば取り下げる。
