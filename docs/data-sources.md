## 券面のマークは7種類

公式の [howto/3.html](https://pokemonfrienda.com/howto/3.html)「アイコン・マークについて」より。

でんせつ / まぼろし / Zワザ / テラスタル / メガシンカ / タッグわざ / ダイマックス。

**仕組みは「2つめのわざの行」に出る**（例: マスカーニャ = テラバースト＋星形マーク）。
**メガシンカだけは1行目**が「メガ○○ にメガシンカ！」になり、実際のわざは2行目にある。

## 公式外に頼っているのは1か所だけ

**ポケエネ**のみ。ファンサイト [pokearcade.jp](https://pokearcade.jp/) の「フレンダピック全弾データベース」を使っている。

- 券面の表面にも印字はあるが、ホロのにじで字がつぶれて**85%しか読めない**
- しかも**OCRが読み違えた2件は、どちらもファンサイトのほうが正しかった**
  （`1-3-003` デオキシス 280→260、`1-5-008` ジャラランガ 278→276。目視確認済み）

そのため精度でファンサイトを上に置き、向こうに無いぶんだけ券面の読み取りで補っている。
**取れなくても止まらない**（`update.sh` のステップ5）。その場合ポケエネは券面から
読めたぶんだけになる。

なお `scripts/raw/legacy_picks.json`（旧ファンサイト由来）は**ローカルの保存済みファイル**で
通信はしない。いま供給しているのは**わざ名18件だけ**。

## 機械で読めなかった分を手で埋める

    npm run manual

ブラウザがひらく（8099。ふさがっていたら次の番号）。**大人が使う管理画面なので漢字を使う。**

- **未入力を埋める** … 足りないところを順に聞いてくる
- **検索して修正** … 番号・名前で探して、どのピックでも直せる

読みたい場所を**3倍に拡大**して上に出す（わざの行／ポケエネの欄）。切り出し座標は
OCR 側（`header_ocr.py` の `MOVE_ORIGIN`、`extra_ocr.py` の `ENERGY_WIN`）と同じものを使う。
**メガシンカのピックは2行目を拡大する**（1行目はわざではないため）。

わざタイプは**券面と同じマーク付き**で選ぶ（`assets/types/*.png`。公式の裏面から切り出したもの）。

入れた値は `scripts/raw/manual.json` に貯まり、`parse_official.py` が**いちばん最後に**当てる
（人が見て入れたものが最優先）。`npm run update` を回しても消えない。**作り直せないので
git から外さないこと。**

空欄で保存すると手入力を取り消し、OCRの読み取り結果に戻る。

**券面にそもそも印字が無いものは出てこない**（スペシャルの★118件、ステータス欄の無いプロモ20件）。

2026-08-14 時点で、**埋められるところはすべて埋まっている**（`npm run gaps` が「まだ埋められるもの: なし」）。
手入力は167ピック / 243項目。

## 精度について

券面OCRはすべて、正解データに対して**カバーできた範囲で100%**を確認している
（5分割交差検証つき。学習側と評価側に同じピックが入らないようにしている）。

この照合の副産物として、**旧ファンサイト由来データの誤りが16件**見つかった
（ステータス8・タイプ3・わざ5）。うち2件は**わざ自体が別物**だった。
ファンサイト pokearcade.jp 側でも**10件**の誤りが見つかっている。

**新しい情報源を足すときは、必ず券面OCRの結果と突き合わせて検証してから使うこと。**
